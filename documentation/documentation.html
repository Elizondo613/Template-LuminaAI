Lumina AI Documentation

Complete setup and customization guide. No prior experience beyond basic HTML editing required.

01 Introduction

Lumina AI is a premium light-mode HTML template designed for AI-powered SaaS products, developer tools, and micro-SaaS startups. It uses a clean whitespace aesthetic with a violet/teal gradient accent system and modern typography to create the polished look that tech products demand.

Sections Included

  • Navbar — Sticky with glassmorphism on scroll, mobile hamburger menu
  • Hero — Announcement chip, headline, CTA buttons, and browser dashboard mockup
  • Logos Bar — Trusted-by company names
  • How It Works — 3 numbered step cards with arrow connectors
  • Features (Bento Grid) — 5 cards: prompt demo, insight bars, compliance badges, integrations, code block
  • Testimonials — 3 cards + animated social proof stats
  • Pricing — 3 plans (Free/Pro/Enterprise) with monthly/annual toggle
  • FAQ — Accordion with animated open/close
  • CTA Banner — Dark gradient final call-to-action
  • Footer — Brand column, 4-link columns, social icons

02 Requirements

Lumina AI requires no build tools, no npm, and no server. It runs entirely in the browser.

  • Any modern browser (Chrome, Firefox, Safari, Edge)
  • A text editor (VS Code recommended)
  • Any static host for deployment (GitHub Pages, Netlify, Vercel, shared hosting)
✦ Open docs/index.html directly in your browser to preview. Everything works immediately — no server needed.

04 Quick Start

1. Preview

Open docs/index.html in any browser. All animations and CDN assets load automatically.

2. Replace brand name

Search for lumina and Lumina in index.html and replace with your product name. The name appears in the nav, hero, CTA section, and footer.

3. Deploy

Upload the three files from docs/ to any static host. For GitHub Pages: push to a repo, then go to Settings → Pages → Branch: main → / (root) → Save.

ℹ Always keep index.html, style.css, and script.js in the same folder. They reference each other with relative paths.

05 Colors & Theme

All colors use CSS custom properties defined in style.css. Change the accent color in one place and the entire template updates.

/* style.css — :root */
:root {
  /* Backgrounds (light mode) */
  --bg: #fafafa;
  --bg2: #ffffff;
  --bg3: #f4f4f6;

  /* Primary accent */
  --violet: #7c3aed;
  --violet2: #a78bfa;
  --violet-light: rgba(124,58,237,0.08);
  --violet-border: rgba(124,58,237,0.2);

  /* Secondary accent (gradients) */
  --teal: #0d9488;
}

Example: Blue/Indigo theme

:root {
  --violet: #2563eb;
  --violet2: #60a5fa;
  --violet-light: rgba(37,99,235,0.08);
  --violet-border: rgba(37,99,235,0.2);
  --teal: #7c3aed; /* gradient end */
}
✦ Always update --violet-light and --violet-border alongside --violet using the same RGB values with low opacity. This keeps hover states, badges and borders consistent.

07 Dashboard Mockup

The hero dashboard is built entirely with HTML and CSS — no images required. Key elements to customize:

Stats cards

<div class="db-card">
  <span class="dbc-label">API Calls Today</span>
  <strong class="dbc-val">142,803</strong>
  <span class="dbc-trend up">↑ 18%</span>
</div>

Bar chart heights

Each bar's height is set via the --h CSS variable as a percentage:

<div class="db-bar" style="--h:70%"><span>T</span></div>
<div class="db-bar active" style="--h:100%"><!-- highlighted bar -->
✦ Add class active to any .db-bar to apply the violet gradient highlight. Only one bar should be active at a time.

08 Bento Features Grid

The features section uses a CSS Grid bento layout. Cards with class bento-wide span 2 columns:

<div class="bento-card bento-wide"> <!-- spans 2 columns -->
<div class="bento-card">          <!-- spans 1 column -->

Typing animation

The prompt text typewriter effect triggers when the card enters the viewport. To change the text, edit the content of .prompt-text.typing in index.html. The JS handles the animation automatically.

Insight bars

Bar fill widths are set inline and animate on scroll:

<div class="ib-fill" style="width:87%"></div>

09 Pricing Toggle

Prices are stored as data attributes on each .plan-amount element. No JavaScript changes needed to update prices:

<span class="plan-amount" data-monthly="49" data-annual="37">49</span>
PlanMonthlyAnnual
Free00
Pro4937
Enterprise— (custom)—

The Enterprise plan uses a .plan-custom element instead of .plan-amount — it is not affected by the toggle.

10 FAQ Accordion

Add a new FAQ item by duplicating a .faq-item block and editing the question and answer:

<div class="faq-item">
  <button class="faq-q" onclick="toggleFaq(this)">
    Your question here?
    <span class="faq-icon">+</span>
  </button>
  <div class="faq-a">
    <p>Your answer here.</p>
  </div>
</div>
ℹ The accordion allows only one item open at a time. Add class open to a .faq-item to have it open by default on page load.

11 Animated Counters

The social proof stats animate when they scroll into view. Values are read from data-count attributes:

<span class="sp-val" data-count="50000">0</span>   <!-- displays: 50,000 -->
<span class="sp-val" data-count="4800000000">0</span> <!-- displays: 4.8B -->
<span class="sp-val" data-count="99.99">0</span>   <!-- displays: 99.99 -->

The counter auto-formats values: thousands get commas, millions get M, billions get B, decimals preserve two places.
