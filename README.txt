QUICK START
------------------------------------------------------
1. Open docs/index.html in your browser — done!
   No build tools, npm, or server required.

2. Replace "Lumina" / "lumina" with your product name
   throughout index.html (Ctrl+F → Replace All)

3. Update your pricing in index.html:
   data-monthly="49" data-annual="37"

4. Change brand colors in style.css under :root {}
   (update --violet, --violet2, --violet-light,
   --violet-border, and --teal)

5. Deploy by uploading the 3 files in docs/ to any
   static host (GitHub Pages, Netlify, Vercel, etc.)

KEY FEATURES
------------------------------------------------------
- Browser dashboard UI mockup (pure HTML/CSS)
- Natural language prompt demo with typewriter effect
- Bento grid features layout (5 unique card types)
- Animated counters with smart formatting (K, M, B)
- Monthly/Annual pricing toggle (data attribute driven)
- FAQ accordion (one item open at a time)
- Insight bars animated on scroll
- AOS scroll animations throughout
- Sticky navbar with glassmorphism blur
- Full mobile responsiveness + hamburger nav

------------------------------------------------------
CUSTOMIZATION QUICK REFERENCE
------------------------------------------------------
Brand color     → --violet in style.css :root
Gradient end    → --teal in style.css :root
Pricing prices  → data-monthly / data-annual in index.html
Dashboard bars  → --h inline style on .db-bar elements
Prompt text     → .prompt-text.typing content in index.html
Countdown       → Not applicable (SaaS template)
Font pair       → --font-display / --font-body in :root
